## Overview

Built as part of a development team at Code Huddle for GYMYG, a US-based virtual gym startup: an admin panel where trainers and coaches add workouts and music and schedule sessions, and a client-side module for live video sessions using WebRTC via the daily.co API.

## Highlights

- NestJS REST APIs with JWT role-based access, serving 10K DAU at under 200 ms P95.
- Stripe monthly subscriptions, $15k+ processed.
- Video load times down ~30% with FFmpeg compression and CloudFront edge delivery.
- CI/CD with GitHub Actions and AWS CodePipeline, deploys 40% faster.
