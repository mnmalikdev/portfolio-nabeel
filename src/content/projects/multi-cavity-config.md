## The problem

Molds can have many cavities, and each one can behave differently. Setting up experiments per cavity used to mean spreadsheets and guesswork.

## The approach

A configuration UI that treats the mold as a grid of cavities, with experiment parameters that can be applied per cavity or in bulk, and results you can compare side by side.
